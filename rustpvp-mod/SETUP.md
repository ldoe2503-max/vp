# RustPvP — мод для Minecraft 1.21.1 (Forge)

Добавляет: АК-47 (хитскан-стрельба), патроны, бинт (хил), HUD в стиле Rust
(полоска здоровья + счётчик патронов), свою вкладку в творческом режиме.

Все модели и текстуры нарисованы с нуля (см. `src/main/resources/assets`) —
никакие файлы из игры Rust не использовались и не копировались.

## Рекомендуемый способ сборки (самый надёжный)

Не собирайте по моим `build.gradle`/`settings.gradle` вслепую — надёжнее
взять официальный шаблон Forge (гарантированно рабочий gradle-wrapper) и
наложить сверху мои исходники:

1. Скачайте официальный **MDK (Mod Developer Kit) для Forge 1.21.1** с
   https://files.minecraftforge.net/ (выберите Minecraft 1.21.1, любую
   recommended/latest сборку Forge) — это zip с уже работающим
   `gradlew`/`gradlew.bat`.
2. Распакуйте его в отдельную папку, например `D:\RustPvpMod`.
3. Скопируйте из этого проекта **поверх** распакованного MDK:
   - `src/main/java/com/rustpvp/` → в `src/main/java/com/rustpvp/` MDK
   - `src/main/resources/assets/rustpvp/` → аналогично
   - `src/main/resources/META-INF/mods.toml` → замените файл в MDK
   - `src/main/resources/pack.mcmeta` → замените файл в MDK
   - Значения из моего `gradle.properties` (mod_id, mod_name, mod_version,
     mod_group_id, mod_authors, mod_description) перенесите в
     `gradle.properties` MDK — остальные строки (версии Forge/Minecraft,
     маппинги) из MDK **не трогайте**, они у них уже согласованы между
     собой и гарантированно рабочие.
4. Удалите из MDK пример-класс `ExampleMod.java` (или что там называется по
   умолчанию), если он остался и конфликтует с `RustPvpMod`.
5. В папке проекта:
   ```
   .\gradlew build
   ```
   Готовый мод появится в `build/libs/rustpvp-0.1.0.jar`.
6. Для проверки в игре сразу из разработки:
   ```
   .\gradlew runClient
   ```

## Установка готового jar в обычный Minecraft

1. Установите Forge 1.21.1 (installer с https://files.minecraftforge.net/)
   как обычно устанавливается любой Forge-мод.
2. Положите `rustpvp-0.1.0.jar` в папку `mods` вашего Minecraft/сервера.
3. Запустите игру профилем Forge 1.21.1 — предметы появятся во вкладке
   творческого режима "RustPvP" (АК-47, патроны, бинт).

## Как это работает

- **АК-47** (`AKItem.java`) — ПКМ стреляет мгновенным лучом (хитскан) от
  глаз игрока на 60 блоков, тратит 1 патрон за выстрел, наносит 6 урона
  первой задетой сущности, кулдаун между выстрелами ~0.3 сек.
- **Патроны** — обычный предмет-стак, ищется в инвентаре при стрельбе.
- **Бинт** (`BandageItem.java`) — ПКМ лечит на 2 сердца сразу + накладывает
  регенерацию на 3 секунды, кулдаун 2 секунды между применениями.
- **HUD** (`RustHudOverlay.java`) — тёмная панель снизу слева: полоска
  здоровья всегда, счётчик патронов появляется только когда в руке АК-47.
  Рисуется закрашенными прямоугольниками через `GuiGraphics`, без готовых
  текстур интерфейса.
