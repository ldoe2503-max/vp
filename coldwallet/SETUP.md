# Cold Wallet — установка и запуск (Windows)

Консольный холодный кошелёк для **Monero (XMR)**, **TON** и **USDT (сеть
TRON/TRC20)**. Все приватные ключи создаются и хранятся только на вашем
компьютере, в зашифрованном файле `%USERPROFILE%\.coldwallet\vault.dat`
(AES-256-GCM, ключ шифрования — из вашего пароля через scrypt). Из сети
приложение обращается только к публичным API для просмотра баланса/курса
и для отправки уже подписанных локально транзакций — приватные ключи
никогда никуда не передаются.

## Вариант А (проще): запуск через Python

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку "Add python.exe to PATH").
2. Скопируйте папку `coldwallet` на свой компьютер, откройте в ней
   PowerShell (Shift + правый клик → "Открыть окно PowerShell здесь").
3. Установите зависимости:
   ```
   pip install -r wallet_app_requirements.txt
   ```
4. Запускайте кошелёк:
   ```
   python wallet_app\main.py
   ```

## Вариант Б: собрать один .exe файл

PyInstaller не кросс-компилирует — `.exe` нужно собрать именно на Windows
(тот `dist/coldwallet`, что уже в этой папке, — Linux-бинарник, собранный
для проверки логики; для Windows нужно собрать заново на вашей машине).

После шага 3 варианта А выполните:
```
cd wallet_app
pyinstaller --onefile --name coldwallet --paths=. ^
  --collect-all coincurve --collect-all bip_utils ^
  --collect-all monero --collect-all tonsdk --collect-all tronpy ^
  main.py
```
Готовый файл появится в `wallet_app\dist\coldwallet.exe` — можно запускать
двойным щелчком или из PowerShell:
```
.\dist\coldwallet.exe
```

## Первый запуск

1. Пункт меню **1 — Создать новый кошелёк**.
2. Приложение офлайн сгенерирует ключи для XMR, TON и USDT-TRC20 и покажет
   три мнемонические фразы (по 24 слова каждая) **один раз**.
   **Перепишите их на бумагу и уберите в надёжное место** — это
   единственный способ восстановить доступ к деньгам. Не фотографируйте,
   не сохраняйте в облако, не отправляйте никому.
3. Задайте пароль для локального хранилища (это отдельный пароль,
   защищающий файл `vault.dat` — он не заменяет мнемоники, а шифрует их
   локальную копию).
4. Дальше при каждом запуске — пункт **3/4/6/7** попросит этот пароль,
   чтобы расшифровать хранилище на время операции.

## Восстановление на другом компьютере

Пункт меню **2 — Восстановить кошелёк из мнемоник**, введите те самые
24 слова для нужных сетей. Адрес пересчитается детерминированно и будет
идентичен исходному (это уже проверено в разработке: generate → restore
даёт тот же адрес для всех трёх сетей).

## Важные ограничения, о которых стоит знать

- **TON**: используется официальная схема мнемоники TON (не BIP39), адрес
  и мнемоника совместимы с Tonkeeper и официальным TON-кошельком — можно
  восстановить там же по тем же 24 словам.
- **Monero — просмотр баланса**: по умолчанию идёт через публичный
  "light wallet" сервер (протокол MyMonero) — ему передаются адрес и
  *view key* (не spend key), этого достаточно чтобы узнать баланс, но
  сервер видит ваши входящие переводы. Если это неприемлемо, поднимите
  свой `monero-wallet-rpc` (см. `wallet_app/chains/send_xmr.py` — там же
  описана настройка) — тогда и просмотр баланса, и отправка идут только
  через процесс, который контролируете лично вы.
- **Отправка XMR** обязательно требует запущенного локально
  `monero-wallet-rpc` (см. инструкцию в `send_xmr.py`) — построение
  Monero-транзакций (кольцевые подписи, выбор decoy-выходов) намеренно не
  реализовано с нуля: ошибка в такой логике может необратимо испортить
  транзакцию или сломать приватность, поэтому используется официальный
  инструмент проекта Monero.
- **Обмен (пункт 7)** идёт через ChangeNOW — нужен бесплатный API-ключ с
  changenow.io. Приложение никогда не выступает стороной, хранящей ваши
  средства во время обмена: вы (или приложение от вашего имени, вашим же
  ключом) отправляете монеты на адрес, который выдаёт ChangeNOW, дальше
  обмен и его комплаенс — их зона ответственности, не ваша и не эта
  программа.
- Забытый пароль от `vault.dat` **не восстанавливается** — восстанавливать
  нужно будет через мнемоники (пункт 2). Файл `vault.dat` стоит
  дополнительно бэкапить (например, на зашифрованную флешку) — тогда для
  восстановления понадобится только пароль, без переписывания мнемоник
  заново.
